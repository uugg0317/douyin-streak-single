# 抖音续火花 2.8：Windows 桌面构建

公开仓库提供源码及构建工具。默认建议先按根目录 README 运行源码；此说明不表示已经发布或验证可安装的 exe。

## 构建

在项目根目录运行：

```powershell
python desktop\build.py
```

构建脚本创建独立虚拟环境，安装锁定依赖及桌面额外依赖，准备 Chromium，再调用 PyInstaller 的 `--onedir` 模式。构建需要网络和可写磁盘目录。

产物位于 `desktop/_build/dist/DouyinStreak/`，通常包含：

```text
DouyinStreak.exe
.env.example
data/
_internal/static/
_internal/playwright-browsers/
```

分发必须包含完整目录，不应只拷贝 exe。构建器只收集代码、静态资源和浏览器，不复制构建机的 `.env`、Cookie、好友台账或日志，并在构建后检查敏感文件。

## 首次运行

双击 `DouyinStreak.exe` 后，程序启动本机服务并打开浏览器，直接进入控制台，不要求设置管理密码。默认监听 `127.0.0.1`；端口 8000 被占用时会在 8001–8009 中寻找可用端口。后台任务默认暂停。

在“凭证”页开始扫码，使用本人抖音 App 确认后自动保存本机登录态。托盘菜单可以打开控制台、打开扫码入口、重启或退出服务。扫码菜单打开的是控制台首页，进入“凭证”页后再操作。

运行数据保存在 exe 同级 `data/`，可选配置使用 exe 同级 `.env`；只读资源在 `_internal/`。这些私有资料不应随已使用过的目录再次分发。更新前停止程序并自行备份数据。

## 验证范围

桌面产物需要单独验证：首次启动、托盘、退出清理、浏览器路径、系统权限和目标机器兼容性。源码隔离测试通过不能替代 exe 实机验收。

此版本仅面向本机使用，不提供公网、局域网、反向代理或隧道共享控制台。无密码门不代表操作系统内其他程序无法访问本机服务。
