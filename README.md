# 抖音续火花 2.8

基于 Python、FastAPI 和 Playwright 的单账号本机工具，提供联系人同步、火花状态查看、勾选台账、手动运行、定时任务和网页内扫码登录。

**此公开版没有管理密码门。启动后直接进入控制台，只允许本机回环地址访问。** 不支持通过公网域名、局域网、反向代理或隧道共享控制台。扫码任务自己的临时校验仍然保留，用于避免不同扫码任务相互干扰。

发布源码不包含个人配置、Cookie、好友名单、发送记录、日志或运行备份。首次运行后生成的这些文件属于使用者自己的私有数据。

## 2.8 的主要变化

- 移除后台密码、管理令牌登录界面及首次启动设密码步骤，直接打开本机控制台。
- 统一页面、服务状态和启动说明的版本号。
- 修复同步时头像地址变化导致的历史重复记录；默认展示本次观察到的好友，历史记录可按需显示。
- 正常火花、重燃中和即将消失的好友纳入火花筛选及一键勾选；无法可靠读取的状态不会自动当作零天。
- 概览和凭证状态颜色更明确，说明文字更清楚；缩小扫码与结果区域，保留四阶段扫码过渡和邮箱收展效果。
- 动态背景根据实际流畅度调整像素预算和绘制频率，保留原有纹理、暂停开关及最高 120 帧目标；设备负载较高时优先保证页面操作流畅。

## Windows 源码运行

需要 Python 3.10 及以上。将完整项目放在可写目录中：

1. 双击 `安装依赖.bat`。它创建本项目的虚拟环境，按 `requirements.lock` 安装依赖并下载 Chromium；此步骤需要网络。
2. 双击 `启动单账号本机版.bat`。
3. 在浏览器打开 <http://127.0.0.1:8000/>，直接进入控制台。
4. 在“凭证”页点击“开始扫码登录”，用本人抖音 App 扫码并确认。二维码显示在当前网页内，成功后自动保存本机凭证。
5. 同步好友、核对火花状态并保存勾选。先用“模拟演练”检查定位流程，再自行决定是否正式发送。

启动脚本默认暂停后台定时发送、自动采集、预热和体检。它不会因为你打开页面而自动发送。停止时在启动窗口按 `Ctrl+C`。

若端口 8000 已被其他实例占用，先确认并停止原实例；不要让两个实例共享同一个数据目录。虚拟环境损坏时，重新运行安装脚本。安装器会保留失效环境的重命名副本，不会删除账号数据。

## Linux 本机运行

需要 Python 3.10 及以上、venv 支持和 Chromium 所需系统库。在项目目录执行：

```sh
bash start.sh
```

脚本首次创建虚拟环境、安装锁定依赖和浏览器组件，然后仅监听 `127.0.0.1:8000`，后台任务默认暂停。如果系统提示缺少 Chromium 依赖，请按 Playwright 的安装提示补齐系统库后重试。

`deploy.sh` 仅保留为本机启动兼容入口，不安装系统服务、不开放端口、不配置反向代理。`douyin-streak.service` 是可选的本机服务示例，路径和运行账号需由使用者自行准备；默认同样暂停后台任务。

## 日常使用与结果含义

- **勾选草稿需要保存。** 保存后的名单才是发送任务使用的名单；未保存时先保存或放弃草稿。
- **同步完成以当前任务结果为准。** 旧台账人数不代表本次同步成功；“本次未观察到”不等同于好友已删除。
- **历史重复整理保持保守。** 只按受支持的头像资源与身份条件合并可确认重复的记录，保留原勾选和发送历史；不同身份或待核对记录不会仅凭昵称合并。
- **同名好友不猜测。** 页面不要求逐个确认“是否同一人”，但真实身份歧义仍会阻止自动选错会话。必要时先在平台设置可区分备注，再重新同步。
- **已确认接受不等于已读或火花必然增长。** 系统核对本次新消息及失败信号；证据不足会标为“待核对”，不能把它当作未发送直接重发。
- **当天去重与待核对保护保留。** “继续未完成”只处理符合重试条件的待处理对象，不自动重发已成功、已拒绝或待核对的消息。
- **模拟演练不发消息。** 它检查页面定位流程，但不能替代真实投递或平台火花增长的验证。
- **凭证保存不等于始终有效。** 凭证页同时显示上次检查状态与时间，失效后可重新扫码更新。
- **定时页展示生效配置。** 部分固定字段只读。后台总开关处于暂停时，今日已有发送记录也不会自动打开后台任务。

## 配置与数据

无需设置管理密码或管理访问令牌。可选配置参见 `.env.example`；源码运行默认使用项目根目录 `.env`，账号数据默认写入 `data/`。这些路径已被 Git 忽略。

请妥善保管以下私有资料，不要随源码上传或分享：

- `.env` 和邮箱授权码；
- `data/state.json` 等浏览器登录态；
- 好友、消息和发送台账；
- 日志、截图、诊断结果及 `data/backups/`。

备份与升级前先停止任务和服务。不要把使用过的工作目录直接压缩发布。项目提供 `tools/make_release.py` 按白名单导出源码，默认排除私有配置、数据、日志、构建产物和 Git 历史。

历史重复整理工具默认只预览：

```sh
python tools/consolidate_contacts.py --data-dir data
```

确认预览后才使用 `--apply`。工具会检查运行占用并先备份原台账，保留可恢复的合并报告；有运行任务或待派发队列时会拒绝写入。

## 开发与验证

使用锁定依赖，避免用本机账号验证自动发送修改。测试应使用临时数据目录、本地模拟页面和虚构凭据。

```sh
python -m unittest discover -s tests -p "test_*.py"
node tests/test_silk_background.cjs
node tests/test_qr_step_motion.cjs
node tests/test_console_status.cjs
```

Python 测试覆盖自有的来源校验、任务协调、发送状态与数据保护。前端测试覆盖扫码恢复、勾选草稿、状态展示和动画生命周期。隔离测试通过不代表真实抖音页面永远不变，也不代表消息一定送达。

桌面源码构建说明见 [desktop/README.md](desktop/README.md)。仓库源码可运行不等于 Windows 安装包已完成实机验收。

## 使用范围

仅用于本人或已明确授权的账号。遵守平台规则及接收方意愿；网页结构、登录校验和平台限制变化都可能导致功能失效。遇到验证、拒绝或不确定结果时应由使用者处理，不提供验证码绕过或风控规避。

本机无密码门只移除了后台登录步骤，不提供跨用户隔离。本机可运行的其他程序仍可能访问本机服务。不要把此版本开放给外部网络使用。
