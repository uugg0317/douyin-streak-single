## 备份

在生产机上，部署前执行：

```bash
ts=$(date +%Y%m%d-%H%M%S)
mkdir -p /root/backups
tar -czf /root/backups/douyin-streak-$ts.tar.gz \
  -C /opt douyin-streak \
  -C /etc/systemd/system douyin-streak.service \
  -C /etc/nginx/sites-enabled uugglx.conf
ls -lh /root/backups/douyin-streak-$ts.tar.gz
```

记下这个 `$ts`。备份包含 `data/` 和 `venv/`，体积会比较大。

## 部署步骤

1. 完成上面的备份，确认 tar 文件存在。
2. 把 `/workspace/streak-2.9-port` 的代码同步到生产，排除数据和运行时目录。不要使用会删除 `data/` 的参数。

```bash
rsync -a \
  --exclude '.git/' \
  --exclude 'data/' \
  --exclude 'venv/' \
  --exclude 'venv.py39.bak-20261027/' \
  --exclude '.cache/' \
  --exclude '.config/' \
  --exclude '__pycache__/' \
  --exclude '.review-work/' \
  --exclude '.env' \
  ./ /opt/douyin-streak/
# GNU chown 没有 --exclude。不要 chown -R 整个 /opt/douyin-streak，以免改到 data/。
find /opt/douyin-streak \
  \( -path /opt/douyin-streak/data -o -path /opt/douyin-streak/venv -o -path '/opt/douyin-streak/venv.py39.bak*' -o -path /opt/douyin-streak/.cache -o -path /opt/douyin-streak/.config \) -prune -o -print0 \
  | xargs -0 chown douyin:douyin
```

3. 不要改 `data/service.env`。密码门、Webhook、小号助手都继续走现有环境变量。
4. `systemctl restart douyin-streak`
5. 验证（不要触发发送）：
   - `systemctl is-active douyin-streak`
   - `curl -sS http://127.0.0.1:8000/api/health` 返回 `sparkkeeper` / `2.9`
   - 打开 https://uugglx.com/ 仍先看到密码门
   - 登录后能看到火花观察时间和灰色/即将消失提示
   - 好友勾选人数与今晚发送结果仍在
   - 下次定时仍是 `2026-11-09 00:00`（Asia/Shanghai）
6. systemd 的 `Description=Douyin Streak 2.8 - Local Console` 只是展示文字，可以以后再改，不影响运行。

## 回滚

若服务起不来、密码门消失、或好友/今日结果不对：

```bash
systemctl stop douyin-streak
# 只回滚程序和配置，不覆盖部署后新写入的 data/（除非 data 已被新代码写坏）
tmpdir=$(mktemp -d)
tar -xzf /root/backups/douyin-streak-<ts>.tar.gz -C "$tmpdir"
rsync -a \
  --exclude 'data/' \
  --exclude 'venv/' \
  --exclude 'venv.py39.bak-20261027/' \
  --exclude '.cache/' \
  --exclude '.config/' \
  "$tmpdir/douyin-streak/" /opt/douyin-streak/
cp -a "$tmpdir/douyin-streak.service" /etc/systemd/system/douyin-streak.service
cp -a "$tmpdir/uugglx.conf" /etc/nginx/sites-enabled/uugglx.conf
systemctl daemon-reload
systemctl start douyin-streak
# 仅当确认 data/ 被写坏时，才从备份恢复 data/：
# rsync -a "$tmpdir/douyin-streak/data/" /opt/douyin-streak/data/
```

把 `<ts>` 换成备份时的时间戳。
